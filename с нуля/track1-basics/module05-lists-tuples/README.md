# Модуль 05. Списки и кортежи

Списки: создание, `append`, индексы, срезы, перебор, `sorted`, `in`,
`join`/`split`. Кортежи — коротко. Вложенные списки (матрицы).

Соглашение о вводе: если в задаче сказано «прочитайте список чисел»,
числа идут в одной строке через пробел.

---

## Шпаргалка

### Список: создание и добавление

```python
numbers = []               # пустой список
numbers.append(5)          # добавить в конец → [5]
numbers.append(8)          # → [5, 8]
len(numbers)               # 2 — количество элементов
```

### Разбор ввода-строки в список чисел

```python
parts = input().split()    # ['3', '7', '1'] — строки
numbers = []
for p in parts:
    numbers.append(int(p)) # [3, 7, 1] — числа
```

### Индексы и срезы — как у строк

```python
a = [10, 20, 30, 40]
a[0]          # 10 — первый элемент
a[-1]         # 40 — последний
a[1:3]        # [20, 30] — срез (правая граница не включается)
a[::-1]       # [40, 30, 20, 10] — перевёрнутый список
a[0] = 99     # списки, в отличие от строк, изменяемы
```

### Перебор

```python
for x in numbers:          # по элементам
    print(x)
for i in range(len(numbers)):   # по индексам
    print(i, numbers[i])
```

### Проверка принадлежности

```python
if 7 in numbers:
    print("есть")
```

### Сортировка

```python
sorted(a)      # новый отсортированный список, исходный не меняется
```

### Сборка строки из списка

```python
words = ["раз", "два"]
" ".join(words)            # 'раз два' — элементы должны быть строками
" ".join(["1", "25"])      # '1 25' — числа переводите через str(x)
```

### Кортежи

```python
point = (3, 7)             # неизменяемый «список»
x, y = point               # распаковка
a, b = b, a                # обмен значений — это тоже кортежи
```

Кортежи удобны, чтобы «склеить» несколько значений; изменять их нельзя.

### Вложенные списки (матрицы)

```python
row = [1, 2, 3]
matrix = []
matrix.append(row)         # matrix[0] — первая строка
matrix[0][1]               # 2 — элемент строки 0, столбца 1
```
