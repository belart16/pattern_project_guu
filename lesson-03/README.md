# Занятие 3. Объектно-ориентированное программирование: отношения классов

Третье, завершающее занятие вводного блока курса «Паттерны объектно-ориентированного
программирования на Python». Разбираем, как классы связаны друг с другом: инкапсуляция
и отношения объектов, композиция и делегирование, наследование и `super()`, миксины
и MRO, абстрактные классы — и когда наследование стоит заменить композицией.
Эти темы — фундамент всех паттернов GoF, к которым мы переходим со следующего занятия.

## Темы

1. Принципы ООП: инкапсуляция, полиморфизм, отношения между объектами
2. Композиция: «has-a», делегирование, внедрение зависимостей
3. Наследование: «is-a», переопределение, `super()`
4. Множественное наследование и миксины, MRO
5. Абстрактные классы и интерфейсы (`abc`)
6. Наследование vs композиция: стратегии и делегирование

## Быстрый старт

```bash
git clone <адрес-репозитория>
cd lesson-03
```

Дополнительных зависимостей не требуется — достаточно Python 3.10+.

## Как работать с заданиями

1. Откройте файл задания, например `tasks/t03_inheritance.py`.
2. Прочитайте условие в докстринге класса/функции и примеры ожидаемого поведения.
3. Замените `raise NotImplementedError(...)` своим решением.
4. Проверьте себя на примерах из докстринга — запустите файл в интерактивном режиме:

```bash
python -i tasks/t03_inheritance.py
>>> Dog("Рекс").speak()
'гав'
```

Автотестов в репозитории нет: итоговую проверку выполняет преподаватель. Решение
оценивается не только по результату, но и по качеству кода.
