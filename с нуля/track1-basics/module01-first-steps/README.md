# Модуль 01. Первые шаги

Первая программа, переменные, ввод и вывод, арифметика, типы `int`, `float`,
`str`, `bool`, f-строки, округление, модуль `math`.

Прочитайте шпаргалку, затем решайте задачи по порядку. Условие каждой задачи —
в начале её файла в папке `tasks/`.

---

## Шпаргалка

### Ввод и вывод

```python
print("Привет, мир!")        # вывод строки
print("a =", 2 + 2)          # несколько значений печатаются через пробел
name = input()               # чтение строки с клавиатуры
age = int(input())           # чтение целого числа
price = float(input())       # чтение дробного числа
```

### Арифметика

```python
x = 7 + 3 * 2                # 13 — приоритет операций как в математике
q = 17 // 5                  # 3   — целочисленное деление
r = 17 % 5                   # 2   — остаток от деления
p = 2 ** 10                  # 1024 — возведение в степень
q, r = divmod(17, 5)         # сразу обе величины: q=3, r=2
print(round(2.333333, 2))    # 2.33 — округление до 2 знаков
```

### Числа и строки

```python
n = "42"
int(n)                       # 42 — строка → целое
str(42)                      # "42" — число → строка
print(f"Возраст: {age}")     # f-строка: значения в фигурных скобках подставляются
print(f"Через год: {age + 1}")  # внутри {} можно выражение
print(type(age))             # <class 'int'> — тип значения
```

### Сравнения и логический тип

```python
print(3 > 2)                 # True
print(3 == 2)                # False (два знака равенства!)
print(2 + 2 == 4)            # True — сравнивать можно выражения
```

### Модуль math

```python
import math
print(math.sqrt(16))         # 4.0
print(math.hypot(3, 4))      # 5.0 — гипотенуза по двум катетам
print(math.pi)               # 3.141592653589793
```

---

## Соглашения о вводе/выводе (важно!)

- Каждая строка ввода читается отдельным `input()`.
- **Не выводайте приглашений** («Введите число: »), если задание прямо
  не требует: тесты подают ввод вслепую и сравнивают весь вывод.
- Вывод сравнивается построчно; концевые пробелы не важны.
- Если задача требует округления — выводите результат `round(...)`,
  например `print(round(x, 2))`.
