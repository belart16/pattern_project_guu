# Занятие 1. Повторение Python: основы, переменные, ветвления, коллекции, циклы, исключения

Это первое занятие курса «Паттерны объектно-ориентированного программирования на Python».
Занятие практическое: вспоминаем синтаксис и систему типов Python, которые понадобятся в
дальнейшем при изучении ООП и паттернов проектирования.

## Темы

1. Основы Python: числа, строки, выражения, форматирование
2. Переменные и область видимости: типы, mutable/immutable, константы, замыкания
3. Операторы ветвления: if/elif/else, логические операторы, тернарный оператор
4. Коллекции: списки, кортежи, множества, словари, строки, двумерные структуры
5. Операторы управления циклом: while, for, break/continue, генераторы списков
6. Ошибки и исключения: try/except/else/finally, raise, with

## Быстрый старт

```bash
git clone <адрес-репозитория>
cd lesson-01
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest
```

Все тесты упадут с `NotImplementedError` — это нормально: задания ещё не решены.

## Как работать с заданиями

1. Откройте файл задания, например `tasks/t01_basics.py`.
2. Прочитайте условие в докстринге функции и примеры ожидаемого поведения.
3. Замените `raise NotImplementedError(...)` своим решением.
4. Запустите тесты:

```bash
pytest tests/test_t01_basics.py          # тесты одной темы
pytest -k task_05                        # тесты одного задания
pytest -k homework                       # только домашние задания
pytest                                   # всё сразу
```

Зелёный тест — задание принято. Тесты проверяют только поведение функции: как именно
написан код внутри, проверяет преподаватель.

## Требования к решениям

- Python 3.10+.
- Решение каждого задания — внутри указанной функции; менять её имя и сигнатуру нельзя.
- Не используйте глобальные переменные там, где не просят явно.
- Тесты должны проходить без предупреждений: `pytest -q` → `56 passed` (число тестов может
  отличаться, главное — нет FAILED и ERROR).
