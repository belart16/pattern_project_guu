## Шпаргалка

### Ветвление

```python
if x > 0:
    print("положительное")
elif x < 0:
    print("отрицательное")
else:
    print("ноль")
```

После условия обязательно двоеточие, тело блока — с отступом 4 пробела.
Отступ — часть синтаксиса Python: он показывает, какие строки относятся
к ветке.

### Сравнения

```python
a == b    # равно (два знака =!)
a != b    # не равно
a < b, a <= b, a > b, a >= b
```

### Логические операторы

```python
if age >= 18 and age <= 65:      # оба условия одновременно
    print("допущен")
if day == "сб" or day == "вс":   # хотя бы одно из условий
    print("выходной")
if not ok:                       # отрицание условия
    print("ошибка")
```

### Цепочка сравнений

```python
if 18 <= age <= 65:              # то же, что age >= 18 and age <= 65
    print("допущен")
```

### Проверка делимости

```python
if n % 2 == 0:                   # чётное
if year % 4 == 0 and year % 100 != 0 or year % 400 == 0:  # високосный
```

### Структурное сопоставление match (Python 3.10+)

```python
match command:
    case "старт":
        print("запуск")
    case "стоп":
        print("остановка")
    case _:                      # «всё остальное»
        print("неизвестная команда")
```
