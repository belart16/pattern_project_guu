# Занятие 4. Введение в паттерны проектирования. Порождающие I: Singleton, Factory Method, Abstract Factory

Четвёртое занятие курса — первое в блоке паттернов GoF. Обсуждаем, что такое
шаблон проектирования и зачем нужен каталог из 23 паттернов, и сразу начинаем
практику с трёх порождающих: Singleton (единственный экземпляр), Factory Method
(фабричный метод) и Abstract Factory (абстрактная фабрика). Многие приёмы вы уже
писали на занятии 3 — теперь у них появились имена.

## Темы

1. Введение: каталог GoF, мотивация, словарь
2. Singleton: единственный экземпляр через `__new__`
3. Фабричные функции и Factory Method
4. Abstract Factory: семейства продуктов
5. Порождающие вместе: синглтон + фабрика, ленивые реестры
6. Когда паттерны не нужны: анти-паттерны и YAGNI

## Быстрый старт

```bash
git clone <адрес-репозитория>
cd lesson-04
```

Дополнительных зависимостей не требуется — достаточно Python 3.10+.

## Как работать с заданиями

1. Откройте файл задания, например `tasks/t02_singleton.py`.
2. Прочитайте условие в докстринге и примеры ожидаемого поведения.
3. Замените `raise NotImplementedError(...)` своим решением.
4. Проверьте себя на примерах из докстринга — запустите файл в интерактивном режиме:

```bash
python -i tasks/t02_singleton.py
>>> President() is President()
True
```

Автотестов в репозитории нет: итоговую проверку выполняет преподаватель. Решение
оценивается не только по результату, но и по качеству кода.
