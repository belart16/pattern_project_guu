# Модуль 06. Словари и множества

Словари «ключ → значение»: доступ, `get`, `in`, изменение, перебор,
порядок вставки. Множества: уникальность, операции `& | -`, `sorted`.
Классический приём — подсчёт частот.

---

## Шпаргалка

### Словарь: основы

```python
ages = {"анна": 19, "борис": 21}
ages["анна"]              # 19 — значение по ключу
ages["вика"] = 18         # добавить новую пару
ages["анна"] = 20         # перезаписать существующую
"вика" in ages            # True — есть ли ключ
len(ages)                 # 3 — количество пар
```

### Безопасный доступ

```python
ages.get("гриша")             # None — ключа нет, ошибки не будет
ages.get("гриша", 0)          # 0 — значение по умолчанию
if "гриша" in ages:           # или явная проверка
    print(ages["гриша"])
```

### Перебор словаря

```python
for name in ages:              # по ключам
    print(name, ages[name])
for name, age in ages.items(): # по парам ключ-значение
    print(name, age)
```

Словарь помнит порядок добавления ключей: перебор идёт в нём.
`sorted(ages)` даёт ключи по алфавиту.

### Подсчёт частот — главный приём модуля

```python
counts = {}
for word in text.split():
    if word not in counts:
        counts[word] = 0
    counts[word] += 1
```

### Словарь со списками

```python
groups = {}
for word in words:
    key = len(word)
    if key not in groups:
        groups[key] = []       # создаём пустой список при первом появлении
    groups[key].append(word)
```

### Множества

```python
s = {3, 1, 3, 2}          # {1, 2, 3} — дубликаты исчезают
s = set()                 # пустое множество
s.add(5)
7 in s                    # False
a = {1, 2, 3}
b = {2, 3, 4}
a & b                     # {2, 3} — пересечение
a | b                     # {1, 2, 3, 4} — объединение
a - b                     # {1} — разность
sorted(a & b)             # [2, 3] — отсортированный список
```

Множества и словарь `counts` — быстрые: проверка `in` почти мгновенна
даже для миллионов элементов.
