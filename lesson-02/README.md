# Занятие 2. Функции и введение в классы

Второе занятие курса «Паттерны объектно-ориентированного программирования на Python».
Сначала глубоко разбираем функции — фундамент, на котором строятся декораторы и паттерны.
Затем знакомимся с классами: атрибутами, методами и «инструментами» класса
(`@classmethod`, `@staticmethod`, `@property`). Это мост к следующему занятию,
посвящённому наследованию, композиции и принципам ООП.

## Темы

1. Функции: параметры, возврат значений, рекурсия, значения по умолчанию
2. `*args` и `**kwargs`, лямбды, функции высшего порядка
3. Замыкания и декораторы
4. Генераторы и `yield`
5. Классы: определение, атрибуты экземпляра и класса
6. Инструменты класса: `@classmethod`, `@staticmethod`, `@property`, магические методы

## Быстрый старт

```bash
git clone <адрес-репозитория>
cd lesson-02
```

Дополнительных зависимостей не требуется — достаточно Python 3.10+.

## Как работать с заданиями

1. Откройте файл задания, например `tasks/t03_decorators.py`.
2. Прочитайте условие в докстринге и примеры ожидаемого поведения.
3. Замените `raise NotImplementedError(...)` своим решением.
4. Проверьте себя на примерах из докстринга — запустите файл в интерактивном режиме:

```bash
python -i tasks/t03_decorators.py
>>> task_13()()
1
```

Автотестов в репозитории нет: итоговую проверку выполняет преподаватель. Решение
оценивается не только по результату, но и по качеству кода.
