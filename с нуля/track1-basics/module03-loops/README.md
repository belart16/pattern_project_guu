Циклы `for` и `while`, `range`, накопление суммы и счётчики, `break`
и `continue`, ввод до sentinel-значения, вложенные циклы.

Условие каждой задачи — в начале её файла в папке `tasks/`.

## Шпаргалка

### Цикл for и range

```python
for i in range(5):          # 0 1 2 3 4 — правая граница не включается
    print(i)
for i in range(1, n + 1):   # 1 2 ... n — от начала до конца включительно
for i in range(10, 0, -1):  # 10 9 ... 1 — с шагом -1
for i in range(0, 10, 2):   # 0 2 4 6 8 — с шагом 2
```

### Цикл while

```python
while n > 0:                # выполняется, пока условие истинно
    digit = n % 10
    n = n // 10
```

`while` выбирают, когда заранее неизвестно, сколько повторений понадобится
(например, ввод до нужного числа).

### Накопитель и счётчик

```python
total = 0                   # накопитель суммы
for i in range(1, n + 1):
    total += i              # то же: total = total + i

count = 0                   # счётчик
for i in range(1, n + 1):
    if i % 7 == 0:
        count += 1
```

### break и continue

```python
while True:                 # «бесконечный» цикл
    x = int(input())
    if x == 42:
        print("угадал")
        break               # выход из цикла
    print("мимо")
```

`continue` пропускает остаток тела цикла и переходит к следующей итерации.

### Вывод без перевода строки

```python
print(1, end=" ")           # 1 2 3 — числа через пробел в одной строке
print(2, end=" ")
print(3)
```

### Двойное присваивание

```python
a, b = 0, 1                 # двум переменным сразу
a, b = b, a + b             # правая часть вычисляется до присваивания
```
