## Шпаргалка

### НОД: алгоритм Евклида

```python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
```

НОК связан с НОД: `lcm = a * b // gcd(a, b)`.

### Разложение на простые множители

```python
factors = []
d = 2
while n > 1:
    while n % d == 0:
        factors.append(d)
        n //= d
    d += 1
# 100 → [2, 2, 5, 5]
```

### Простые числа: перебор и решето

Перебор делителей до n − 1 понятен, но медленный; до корня — быстрее:

```python
def is_prime(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True
```

### Целые числа Python — безграничны

`2 ** 1000` и `100!` вычисляются обычным `*` — длинная арифметика встроена
в язык. Это отличает Python от C/C++ (где нужны спецбиблиотеки).

### Римские числа

```python
VALUES = [(1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
          (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
          (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I")]
```

Кодирование: идёте по парам сверху вниз, пока число ≥ значения — приписывайте
букву и вычитайте. Декодирование: буква меньше следующей — вычитаем.

### Системы счисления

Перевод делением: забирайте остатки `n % base`, уменьшая число `n //= base`,
пока не станет 0; остатки читаются в обратном порядке. Цифры выше 9 —
буквы: `"0123456789ABCDEF"`.

### Числа-«игрушки»

- Палиндром: `s == s[::-1]` по строковому представлению.
- Число Армстронга: сумма цифр в степени длины числа равна самому числу
  (153 = 1³ + 5³ + 3³).
- Гипотеза Коллатца: n чётное → n/2, нечётное → 3n+1; рано или поздно
  получаем 1.
- Гольдбах: всякое чётное n ≥ 4 есть сумма двух простых.
