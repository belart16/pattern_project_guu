## Шпаргалка

### Индексы и срезы

```python
s = "программа"
s[0]        # 'п' — первый символ (нумерация с нуля)
s[-1]       # 'а' — последний символ
s[0:3]      # 'про' — символы с 0 по 2 (правая граница не включается)
s[3:]       # 'грамма' — до конца
s[:4]       # 'прог' — с начала
s[::-1]     # 'аммаргорп' — строка задом наперёд
len(s)      # 8 — длина
```

### Строки неизменяемы

```python
s[0] = "П"                 # ошибка! отдельный символ не изменить
s = "П" + s[1:]            # так можно: собрать новую строку
```

### Регистр и пробелы

```python
"привет".upper()           # 'ПРИВЕТ'
'ПРИВЕТ'.lower()           # 'привет'
"  hi  ".strip()           # 'hi' — убрать пробелы по краям
"привет мир".capitalize()  # 'Привет мир' — только первая буква
```

### split и join

```python
"один два три".split()     # ['один', 'два', 'три'] — список слов
"a,b,c".split(",")         # ['a', 'b', 'c'] — с разделителем
"report.pdf".rsplit(".", 1)  # ['report', 'pdf'] — один раз справа
"-".join(["a", "b", "c"])  # 'a-b-c' — собрать строку из списка
```

### Поиск и подсчёт

```python
"мама".count("м")          # 2 — сколько раз встречается
"hello".find("l")          # 2 — индекс первого вхождения, −1 если нет
"abc".startswith("ab")     # True
"abc".endswith("c")        # True
```

### Проверки символов

```python
"5".isdigit()              # True — символ цифра?
"abc".isalpha()            # True — символ буква?
```

### replace

```python
"file name.txt".replace(" ", "_")   # 'file_name.txt'
```

### Коды символов

```python
ord("a")                   # 97 — код символа
chr(98)                    # 'b' — символ по коду
```
